# EtheRings Public Mirror Sync Policy

1. This repository has independent Git history.
2. Private Git history is never merged, rebased, pulled, or mirrored here.
3. Private repositories must never be configured as remotes.
4. Sync is performed only through reviewed file-level export.
5. Every export starts from an explicit allowlist.
6. Every sync undergoes secret, privacy, and content review before commit.
7. Private operational, security, and deployment material remains excluded.
8. Source code may be added only after a separate publication audit.
9. Public commits describe public-content changes only.
10. Public history must not pretend to share ancestry with private history.
11. Public publication does not imply a production deployment or change.
12. Website source remains in the separate private EtheRings landing-page
    repository and is not synced here.
