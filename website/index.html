04 / Product evolution

Built, testing, then expanding.

These are product stages, not promised release dates. Each next stage depends on what public testing proves.

  1. CompletedMVP

    The first Android version established walking, Draw and game Rings. It is retired; its accounts and balances do not move to Alpha.

  2. Live nowAlpha 1.2.1a

    Test email sign-in, a wallet, Ring progression, Boxes and the player Marketplace with test assets on Solana Devnet.

  3. In progressAlpha quality

    Investigate step tracking across phones, Ring and Box failures, screen loading and Marketplace purchase checks. Public tester reports guide the fixes.

  4. PlannedBeta

    Develop Match-3 play where the Ring collection matters. Gameplay rules and timing will follow Alpha testing and a separate Beta specification.

  5. LaterMainnet

    Prepare a separate production release only after the game economy, security and launch requirements are approved and checked.

05 / Why blockchain

Blockchain is not used to count steps.

The game backend handles steps and ERT. Solana Devnet provides Silver ownership and player-approved blockchain actions.

Public Alpha live · Devnet
Game resources

Movement and play

  • Steps are tracked in the Android app
  • ERT is an off-chain game resource
  • Cooper Rings are game items, not NFTs
  • Draw and progression use game resources
Solana Devnet

Ownership and approved actions

  • ERU and Silver assets use Solana Devnet
  • The self-custodial wallet signs locally
  • Players need test SOL for network fees
  • Eligible Silver assets can be transferred or traded
  • The game verifies finalized blockchain results
