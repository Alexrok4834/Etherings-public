# Public website

This folder contains the static website published at
[etherings.xyz](https://etherings.xyz/): page source, styles, images, video,
public whitepaper, sitemap and robots file. It is part of the Public Alpha
source so you can inspect how the game is presented as well as how it works.

To preview it locally, run `python -m http.server 8000` from this folder and
open `http://localhost:8000/`. The Android download button points to the
official public test APK; it is not served by this local preview.

The version and release summary in `index.html` describe the published
1.2.1a Alpha. Later release updates must be checked against the public APK
and its release metadata before this page is changed.

The current page uses three frames from October 5 Public Alpha recordings and the owner-provided Alpha demo as a local video, with a direct YouTube link. The web copy masks a personal email visible in the footage. The screenshots predate 1.2.1a and are dated on the page; the earlier MVP imagery and video are no longer used. The site also links to the project Discord, X, company LinkedIn and founder LinkedIn. The video section uses a balanced, fixed-size player (225 px on desktop and 180 px on narrow screens). The header links to Contacts in the footer. Its community and founder links use full text without icons, and its page and community links form two equal columns. The former latest-update section was removed; public testing is section 06. The CSS URL changes with its content so returning visitors receive the current layout.
