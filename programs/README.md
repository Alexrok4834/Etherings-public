# Solana Programs

and the current deployed Devnet runtime are not represented by these files.

- eru-gateway/ — exact ERU operation, fee, replay and settlement context.
- eru-hook/ — Token-2022 Transfer Hook enforcement for ERU.
- silver/ — Silver Box/Ring identity/state, collection boundary and transfer-cooldown logic.

Deployment/governance scripts, signer files, RPC credentials and private proof tooling are intentionally excluded.
